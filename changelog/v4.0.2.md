# v4.0.2

This release adds a client-neutral identity query and signs release checksums
with Sigstore Keyless.

## Added

- `keychain-auth identity [--json]` reports the binary version, sha256 of the
  running executable, store mode, config path, socket path, PID, and protocol
  version. Clients can use it to verify the daemon on the other end of the
  socket before sending sensitive data. The command contains no
  application-specific policy.
- Release artifacts are signed with `cosign sign-blob`. Sigstore bundles are
  published for `checksums.txt` and for every archive. Verification
  instructions are in `docs/signing.md`.

## Notes

Sigstore proves provenance. It does not provide Windows Authenticode trust or
Microsoft SmartScreen reputation, which need a trusted CA certificate.
